# S1.08 - Lambdas & Streams

## 📌 Exercise Description
Introduction to Java 8 Lambdas and Streams API: filtering, transforming and sorting collections using functional programming patterns, functional interfaces, and method references.

## ✨ Functionalities

### Level 1 - Lambdas and Streams
- **Ex1:** Filter strings containing the letter 'o'
- **Ex2:** Filter strings containing 'o' AND longer than 5 characters
- **Ex3:** Print list elements using a lambda
- **Ex4:** Print list elements using method reference
- **Ex5:** Custom functional interface returning Pi value
- **Ex6:** Sort strings shortest to longest
- **Ex7:** Sort strings longest to shortest
- **Ex8:** Custom functional interface to reverse a String

### Level 2 - Functional Data Manipulation
- **Ex1:** Filter names starting with 'A' and exactly 3 letters
- **Ex2:** Format integers with e/o prefix based on even/odd
- **Ex3:** Functional interface for arithmetic operations (sum, subtract, multiply, divide)
- **Ex4:** Sort alphabetically, filter by 'e', replace 'a' with '4', show only numeric elements

## 🛠 Technologies
- Java 21
- Java 8 Streams API
- Functional Interfaces (java.util.function)
- Lambda expressions
- Method references
- Maven 3.9.11
