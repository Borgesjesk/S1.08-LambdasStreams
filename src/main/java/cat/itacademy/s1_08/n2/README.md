# N2 - Functional Data Manipulation

## 📌 Exercise Description
Advanced use of lambdas and streams for complex filtering, transformation, sorting and custom functional interfaces for arithmetic operations.

## ✨ Exercises
- **Ex1:** Filter names starting with 'A' and exactly 3 characters
- **Ex2:** Map integers to strings with e/o prefix using stream().map() and Collectors.joining()
- **Ex3:** @FunctionalInterface OperacioInterface for sum, subtract, multiply and divide operations
- **Ex4a:** Sort mixed list alphabetically by first character using charAt(0)
- **Ex4b:** Sort strings containing 'e' first using custom Comparator lambda
- **Ex4c:** Replace 'a' with '4' in all elements using stream().map()
- **Ex4d:** Filter only numeric elements using chars().allMatch(Character::isDigit)

## 🛠 Technologies
- Java 21
- Streams API, Lambda expressions
- @FunctionalInterface
- Collectors.joining()
- Maven
