# N1 - Lambdas and Streams

## 📌 Exercise Description
Introduction to lambda expressions, Streams API, method references and custom functional interfaces.

## ✨ Exercises
- **Ex1:** Filter strings containing 'o' using stream().filter()
- **Ex2:** Filter strings containing 'o' AND longer than 5 using chained predicates
- **Ex3:** Print months list using forEach() with lambda
- **Ex4:** Print months list using forEach() with method reference (System.out::println)
- **Ex5:** @FunctionalInterface PiValueInterface returning a double value
- **Ex6:** Sort strings shortest to longest using Comparator.comparingInt(String::length)
- **Ex7:** Sort strings longest to shortest using .reversed()
- **Ex8:** @FunctionalInterface ReverseInterface using StringBuilder.reverse()

## 🛠 Technologies
- Java 21
- Streams API, Lambda expressions, Method references
- @FunctionalInterface
- Maven
